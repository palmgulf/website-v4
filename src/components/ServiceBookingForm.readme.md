# ServiceBookingForm Component

A form for booking services with validation.

## Features
- Form validation for required fields
- Responsive styling with Flexbox
- Console logs form data on submit
- Supports text, email, date, and select inputs

## Usage
```jsx
import ServiceBookingForm from './ServiceBookingForm';

// In your component
<ServiceBookingForm />
```

## Styling
- Uses CSS Modules for scoped styling
- Defined in `ServiceBookingForm.module.css`
